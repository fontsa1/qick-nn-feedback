The deployed RTL closes at N = 1, 2 and 4 (pb) and 16 (free), and fails at N = 8 (pb, −0.011 ns) and N = 32 (free, −0.183 ns). Only N = 4 and N = 16 are near zero (+0.002 ns); N = 1 and N = 2 have +0.171 and +0.103 ns.

**Limiting path:** NN_live's fused tail (the last ACC_L iteration computes the rectified units, the signed sums and the saturating select in one cycle) driving `res_o` combinationally into the two CDC hold registers and into `lr_1_reg`. It is the worst path at N = 2, 4, 8 and 16. At N = 1 the worst path is NN_live's loop-init register into an accumulator; at N = 32 an accumulator DSP path, with failures spread over all units (607 of 1,103 in dac_gate's DAC-domain path; `scaling_study/FINDINGS.md`).

**Remedy (OOC only, not deployed, not re-verified):** one extra tail register. Variant T (NN_live re-synthesized with one more ACC_L stage, register-free window gate, same 10-cycle end-to-end latency) closes N = 8 at +0.029 ns and N = 4 at +0.063 ns; variant ZL (gate register moved onto `res_o`) closes N = 8 at +0.006 ns.

## Integration penalty

OOC N = 1: +0.171 ns. The same unit's decision path inside the full design:

| build | worst path through NN_live | NN_live → CDC hold registers | penalty vs OOC N = 1 |
|---|---|---|---|
| v1.41 (`scaling_study/FINDINGS.md`) | −0.141 ns | −0.042 ns (live_res_cdc_0) | 0.171 + 0.141 = 0.31 ns (NN_live), 0.171 + 0.042 = 0.21 ns (CDC) |
| v1.44 (this folder) | +0.001 ns | +0.021 ns (cdc_0), +0.031 ns (cdc_1) | 0.17 ns (NN_live), 0.15 ns (CDC) |

OOC N = 1's +0.171 ns is the unit's worst path, so every path of the unit, the tail included, had at least that; the penalties are lower bounds. In v1.44 the worst path through NN_live is no longer the tail but the weight-ROM lookup (`ap_start_reg` → `WROM_U/q0_reg[8]`, +0.001 ns); the tail into the CDC hold registers is at +0.021 ns. The full design costs ~0.2 ns of the unit's OOC margin (at least 0.15–0.17 ns in v1.44, 0.21–0.31 ns in v1.41). v1.44 closes where v1.41 did not, by 1–31 ps on these paths. With N = 2 already at +0.103 ns out of context, an integrated build with two or more units would be expected to fail on the tail path unless it carries the extra tail register, whose +0.03–0.06 ns out-of-context gain is itself smaller than the integration penalty. **Timing on the tail path, not resources, is the first limit.** No integrated multi-unit build was made.
